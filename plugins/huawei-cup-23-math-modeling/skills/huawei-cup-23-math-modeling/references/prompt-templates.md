# Ready-to-paste prompts

## Start a full project

```text
Use $huawei-cup-23-math-modeling in full-run mode. Read all problem files and official attachments first. Build a source-backed requirement matrix, then proceed through analysis, reproducible computation, evidence review, paper drafting, AI-use disclosure, render QA, and submission audit. Keep the official cover/template intact, preserve anonymity after the cover, and do not upload or send anything. Ask before freezing the final PDF/MD5.
```

## Resume from computation

```text
Use $huawei-cup-23-math-modeling in compute mode. Existing artifacts are in <paper_output>. Re-read the requirement matrix and evidence records, inspect the current code/results, run the missing computations, and report reproducibility, validation, sensitivity, and unresolved issues. Do not write final claims from stale or unverified outputs.
```

## Audit a draft

```text
Use $huawei-cup-23-math-modeling in audit mode. Inspect <docx/pdf/project folder> against the current official announcement, format specification, template, and AI-use regulation. Produce a severity-ranked report for rule, anonymity, citation, numerical consistency, layout, PDF, filename, MD5, and attachment issues. Do not silently modify the submission.
```

## Freeze a submission package

```text
Use $huawei-cup-23-math-modeling in submission mode. Given a local <final PDF>, <question letter>, and a locally held team number, run every local audit, render and inspect the PDF, create an immutable copy, compute MD5 from those exact bytes, and write a manifest. Do not paste or upload the team number; do not upload or transmit the package.
```
